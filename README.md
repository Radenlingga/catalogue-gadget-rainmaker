A catalogue photograph of an impossible gadget: the Rainmaker, a desktop device that parks a tiny rain cloud over one houseplant and waters it with its own private weather. The entry program writes the photograph to /output/entry.png.

## Run it

```sh
python3 main.py  # writes /output/entry.png (set MAKEFUN_OUTPUT_DIR to redirect)
```
